# WindowsForms
Učební materiál pro předmět Programování 2.  
Windows Forms (WinForms) je technologie v programovacím jazyce C#, která slouží k vytváření grafických aplikací pro Windows.  
Oproti konzolovému programování zde uživatel pracuje myší a klávesnicí s grafickým rozhraním.  
Aplikaci tvoří ovládací prvky, např. Button, TextBox, Label, CheckBox a mnoho dalších.  

Ve WF lze vytvořit jednoduchou aplikaci typu:
- kalkulačky
- evidence studentů
- jednoduchého skladového systému
- programu pro práci se soubory
- databázové aplikace
- interního firemního programu
- jednoduchého školního projektu

## Pojmy
**Form** = samotné okno aplikace  
**Control** = prvek umístěný v okně  
**Event** = událost, například kliknutí na tlačítko  
**Event handler** = metoda, která na událost reaguje
